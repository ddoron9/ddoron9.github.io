# HEARTBEAT.md

# Default: keep quiet unless there is a meaningful update.

## Heartbeat checklist (lightweight)

1) `/status` 성격 점검 (모델/비용/오류 징후)
2) 최근 자동화 작업 실패 여부만 확인
3) 새로 알릴 가치가 있을 때만 보고

## Report only when

- 실패/에러가 반복됨
- 24시간 내 중요한 액션이 필요함
- 비용/모델 설정이 정책과 어긋남

## Stay silent when

- 새 이슈 없음
- 기존 이슈와 동일
- 야간(23:00~08:00) 비긴급
